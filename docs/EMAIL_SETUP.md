# إعداد الإيميل (Resend + دومينك)

المنصة ترسل كل إيميلاتها عبر **Resend**: الاستلام، رمز التأكيد، تحديثات الحالة، والتقييم.

## الخطوات

1. **أنشئ حسابًا في Resend:** من resend.com، ويكفي الحساب المجاني (حتى ٣٠٠٠ إيميل شهريًا).
2. **أضف دومينًا فرعيًا للإرسال:** من Domains ← Add Domain. أنصح بدومين فرعي مثل `mail.YOUR-DOMAIN.com` بدل الدومين الرئيسي، لأنه:
   - ما يأثر على إيميلات الشركة الحالية (Google Workspace أو Outlook) ولا على سجل SPF الأساسي.
   - يحمي سمعة الدومين الرئيسي إذا صار أي خلل في الإرسال.
   - اختر المنطقة الأقرب، مثل `eu-west-1`.
3. **أضف سجلات DNS:** Resend يعطيك ٣–٤ سجلات تضيفها عند مزوّد الدومين (GoDaddy أو Cloudflare أو SaudiNIC أو غيرها)، أو يضيفها مسؤول تقنية المعلومات عندكم:
   - `TXT` باسم `resend._domainkey.mail` (DKIM)
   - `MX` باسم `send.mail` (ارتداد البريد)
   - `TXT` باسم `send.mail` بقيمة `v=spf1 include:amazonses.com ~all` (SPF)
   - **اختياري ومستحسن:** `TXT` باسم `_dmarc.mail` بقيمة `v=DMARC1; p=none;`
4. **تحقّق من الدومين:** اضغط Verify في Resend. التحقق عادة يأخذ دقائق، وقد يمتد لـ٢٤ ساعة.
5. **أنشئ مفتاح API:** من API Keys ← Create، بصلاحية Sending access، ومقيّد بهذا الدومين فقط.
6. **أعطني هذه القيم وأضيفها كأسرار في Lovable Cloud:**

| السر | مثال |
|---|---|
| `RESEND_API_KEY` | `re_xxx` |
| `EMAIL_FROM` | `ســـم <hello@mail.YOUR-DOMAIN.com>` |
| `EMAIL_REPLY_TO` | إيميلك اللي تبي الردود توصله |
| `ADMIN_EMAIL` | الإيميل اللي بتسجل فيه كمدير |

## ملاحظة على اسم مجمر

إذا كان الدومين دومين مجمر، فالمستلم بيشوف اسم الدومين في عنوان المرسل، وهذا يتعارض مع شرط "دون أي إشارة لمجمر". الحلول:

- **دومين مستقل للمنصة** (مثل `sum.sa`)، وهذا الحل الأنظف.
- **أو** تقبل ظهور الدومين في عنوان المرسل فقط. الاسم الظاهر للمستلم بيكون "ســـم" في كل الأحوال.

## Cloudflare Turnstile (الحماية من السبام)

1. من dash.cloudflare.com ← Turnstile ← Add site، وأضف دومين المنصة.
2. أعطني الـ Site Key والـ Secret Key، وأضيفهما كـ `VITE_TURNSTILE_SITE_KEY` و`TURNSTILE_SECRET_KEY`.
