# ســـم — وش تبي؟

منصة لاستقبال الطلبات من الزملاء والعملاء. هذا الملف هو المرجع الأساسي لأي مبرمج يعمل على المشروع: القرارات المحسومة، نموذج البيانات، الصلاحيات، والحالات. التفاصيل التنفيذية لكل مرحلة في `docs/lovable-prompts/`.

- الواجهة عربية بالكامل واتجاهها RTL.
- لا يُذكر "مجمر" في أي مكان بالواجهة.
- التقنية: Lovable (React + Vite + TypeScript + Tailwind + shadcn/ui) مع Lovable Cloud (Supabase: Postgres + Auth + Edge Functions + Realtime + Storage) والإيميلات عبر Resend.

## ٢. القرارات المحسومة (مراجعة التعارضات)

| # | البند | القرار |
|---|---|---|
| 1 | الصلاحيات | تُعيّن يدويًا من المدير. المسجّل الجديد = `basic` يرى طلباته فقط. |
| 2 | تعديل التاريخ للزميل | يظهر زر "أجّل طلبك" فقط لمستخدم بصلاحية `colleague` وفقط عندما يكون تنبيه الضغط فعّالًا (الشرط يُحسب في الخادم لحظة الطلب). التأجيل فقط (التاريخ الجديد ≥ القديم)، لطلباته المفتوحة فقط، ويُحفظ في الأرشيف. |
| 3 | رسائل الصديق العامة | يوميًا (بتوقيت الرياض): رسالة واحدة تُنشر بلا إذن بصلاحية ١٠ دقائق (المدير فقط يعدّل المدة)، و٩ رسائل تنتظر اعتماد المدير الذي يحدد مدتها. |
| 4 | تنبيه الزميل | يُعد الطلبات **المفتوحة** التي `who_are_you = colleague` وتاريخ `deadline_date` خلال ٥ أيام من اليوم. إذا تجاوز العدد ١٠ تظهر الرسالة: "إذا تقدر تأجل طلبك ترا عندي {N} طلب من الزملاء وكلها مواعيدها خلال الأيام الخمسة الجاية، روح لطلبك وحدّث تاريخ الاستلام بالموعد اللي يناسبك." |
| 5 | السرية | الصديق يرى نوع الطلب وحالته وتواريخه فقط، بلا الموجز ولا البيانات الشخصية، وتُخفى عنه طلبات العملاء كليًا. أبوي وأمي يرون الطلبات (بلا بيانات شخصية) ومعرض الأعمال. |
| 6 | لون التحذير | كهرماني بإطار وأيقونة. |
| 7 | "وصل الإيميل والأمور طيبة" | الطلب صالح من لحظة الإرسال. إيميل الاستلام فيه رابط تأكيد الإيميل. الزر في الموقع يسجل الإقرار ويربط الإيميل بالطلب ويحفظ الاسم والإيميل في المتصفح لتعبئتهما المرة القادمة، ثم يعرض "كفو". |
| 8 | أبوي/أمي | خيار مرح. يظهر حقل الجوال، والتحقق في الخادم فقط. حتى يضيف المدير الرقم: أي محاولة تُرفض. بعد أول تحقق ناجح: يُقفل الخيار للأبد ويُرفض أي محاولة لاحقة حتى بالرقم الصحيح. رسالة الرفض: "انت مو أبوي، خلك من المزح وعب البيانات بارك الله فيك" (نفس النص للخيارين). |
| 9 | السلايدر | حركة تلقائية هادئة، سحب بالماوس/اللمس، سكرول أفقي من التراكباد. **لا** يلتقط عجلة الماوس العمودية. يتوقف عند المرور بالمؤشر. |
| 10 | عدد الأعمال الظاهرة | جوال ≈ 1.3، تابلت 3، شاشة كبيرة 4. |
| 11 | العدادات | عند تحويل طلب إلى "تم" يفتح المدير نافذة إلزامية: يختار العداد (مع اقتراح افتراضي حسب النوع) والكمية، أو "لا يُحسب". |
| 12 | تعديل الأرقام يدويًا | الرقم المعروض = `base_value` (يعدّله المدير) + مجموع إضافات الطلبات المكتملة. إرجاع طلب من "تم" يحذف إضافته. |
| 13 | الأعياد | الفطر ١–٣ شوال، والأضحى ١٠–١٣ ذو الحجة (أم القرى)، والجمعة. تُحفظ في جدول `holidays` يعدّله المدير (لتصحيح الرؤية). التحذير يظهر على **تاريخ "اللي ما أتعداه" فقط**. |
| 14 | كود الطلب | `YYMMDD` هجري (أم القرى) + `12` صباحًا (00:00–11:59 بتوقيت الرياض) أو `13` مساءً + رقم تسلسل الطلب في اليوم بخانتين (01–99)، ويصبح ثلاث خانات إذا تجاوز ٩٩. مثال: `4704131203`. |
| 15 | إجابات "يبيله" | تصل المدير كإشعار، والحالة لا تتغير تلقائيًا. |
| 16 | "اللي أبيه مو بالاختيارات" | تظهر خانة نص إجبارية "وش هو؟". نوع الطلب اختيار واحد. |
| 17 | "هلا بابا" / "هلا حبيبتي" | جزء من اسم الخيار في القائمة. |
| 18 | خيارا أبوي وأمي | ظاهران دائمًا (انظر البند 8). |
| 19 | الحسابات | تسجيل جديد + دخول + نسيت كلمة المرور. الطلب المرسل قبل التسجيل يرتبط بالحساب (عبر معرف الطلب المحفوظ في المتصفح + الإيميل). تعديل الإيميل يعيد إرسال إيميل الاستلام. |
| 20 | النصوص | إيميل الاستلام: "استلمت طلبك وأبشر باللي يسرك" + كود الطلب + رابط تأكيد الإيميل. صفحة التقييم لطلب حالته "اعذرني": "أنا اعتذرت عن طلبك". تقييم واحد لكل طلب. |
| 21 | الجوال في تقييم الخدمة | يصير إجباريًا إذا اختار واتساب أو اتصال أو فاكس. |
| 22 | الحالات | التنقل بينها بحرية مع سجل لكل تغيير. |
| 23 | أمان الكود | روابط الإيميل تحمل رمزًا عشوائيًا (`access_token`). الإدخال اليدوي يتطلب الكود + الإيميل. |
| 24 | رمز التأكيد | ٤ أرقام، صلاحية ١٠ دقائق، ٥ محاولات، مخزّن مشفّرًا (SHA-256 + salt)، وإعادة الإرسال بعد ٦٠ ثانية. |
| 25 | رقم الوالدين | يُخزّن مشفّرًا (hash) ويُقارن في الخادم، مع حد محاولات لكل IP. |
| 26 | الحماية | كل الصلاحيات تُطبّق بـ RLS ووظائف خادم. الأدوار في جدول `user_roles` منفصل. |
| 27 | الإيميل | Resend بدومين خاص، انظر `docs/EMAIL_SETUP.md`. |
| 32 | الخصوصية | صفحة `/privacy` + سطر موافقة تحت الاستمارة + Cloudflare Turnstile على الاستمارة والمحادثة العامة. |

## ٣. خيارات القوائم

**نوع الطلب** (`request_type`) مع العداد المقترح عند الإتمام:

| المفتاح | النص | العداد المقترح |
|---|---|---|
| `creative_direction` | توجه إبداعي | `creative_direction` |
| `social_content` | محتوى منشور بمنصات التواصل الاجتماعي | `social_content` (يُسأل عن عدد المنشورات) |
| `initial_marketing_plan` | خطة تسويق أولية | `initial_marketing_plan` |
| `full_marketing_strategy` | استراتيجية تسويق متكاملة | `full_marketing_strategy` |
| `video_idea` | فكرة فيديو | `creative_direction` |
| `video_script` | سكريبت فيديو | `social_content` |
| `national_day_video` | فكرة فيديو لليوم الوطني | `creative_direction` |
| `founding_day_video` | فكرة فيديو ليوم التأسيس | `creative_direction` |
| `other` | اللي أبيه مو بالاختيارات | بلا اقتراح (يجب الاختيار) |

**من أنت** (`who_are_you`): `friend` صديق، `colleague` زميل، `client` عميل، `teacher` أستاذ، `father` أبوي "هلا بابا"، `mother` أمي "هلا حبيبتي".

اختيار تاريخ اليوم مسموح للجميع **عدا** `client`.

**القطاع** (`sector`): `education` التعليم "أرحب"، `health` الصحة، `food_beverage` الأغذية والمشروبات، `retail` التجزئة، `tech` التقنية، `other` غير كذا اعذرني من بدري.

**تفضيل التواصل:** `whatsapp` واتساب، `call` اتصال، `email` إيميل، `fax` فاكس، `visit` أجيك بحول الله.

## ٤. الحالات (`request_status`)

| المفتاح | الاسم | إيميل؟ | شرط |
|---|---|---|---|
| `new` | توه | لا (إيميل الاستلام فقط) | — |
| `great` | رهيب | "طلبك واضح ووافي ويحمس، بديت بالعمل عليه وقريب بوافيك بالتفاصيل." | — |
| `needs_info` | يبيله | "طلبك ينقصني لإتمامه شوية تفاصيل." + الأسئلة + زر لصفحة `/answer` | ٢–٩٩ سؤالًا |
| `complete_brief` | وافي | "طلبك وافي وكافي وبإذن الله قريب بوافيك بالتفاصيل ونعمل مع بعض أحلى شغل بحول الله وفضله وكرمه ومنته." | — |
| `declined` | اعذرني | "اعذرني، قدرك عالي ويعز علي أرفض لك طلب، لكن ما أقدر إني أساعدك لهذه الأسباب:" + الأسباب | الأسباب إلزامية |
| `done` | تم | البيت "إذا تم شيء بدا نقصه ... ترقب زوالًا إذا قيل تم" + "الحمدلله على التمام وأستغفر الله لي ولك من كل ذنبٍ ونقصان، أرجو منكَ إن كان وقتك سامحًا أن تعطيني تقييمك وتزودني بمقترحاتك" + زر "الذهاب لصفحة التقييم" | نافذة العداد (بند 11) |

## ٥. الأدوار (`app_role`)

| الدور | الصلاحيات |
|---|---|
| `admin` | كل شيء. |
| `basic` | طلباته فقط. |
| `friend` | قائمة الطلبات (النوع، الحالة، التواريخ، الكود) بلا بيانات شخصية ولا موجز، وبلا طلبات العملاء. الرسائل العامة حسب البند 3. |
| `colleague` | طلبات `who_are_you = colleague` بلا بيانات شخصية. عداد الضغط وزر التأجيل (البندان 2 و4). |
| `loyal` | (للعملاء) "طلب جديد" من لوحته بالبيانات المحفوظة. الاسم والإيميل يُعدلان من الملف الشخصي فقط. |
| `father` / `mother` | كل الطلبات بلا بيانات شخصية + معرض الأعمال. |

**البيانات الشخصية:** الاسم، الإيميل، الجوال، العنوان، `user_id`.

## ٧. وظائف الخادم (Edge Functions)

| الوظيفة | الغرض |
|---|---|
| `submit-request` | يتحقق (Turnstile، قواعد التواريخ، الوالدين)، ينشئ الكود، يرسل إيميل الاستلام. |
| `confirm-email` | `?t=access_token`، يسجل `email_confirmed_at`. |
| `acknowledge-request` | زر "وصل الإيميل والأمور طيبة". |
| `send-otp` / `verify-otp` | رمز الأربعة أرقام. |
| `link-requests` | ربط طلبات الضيف بالحساب بعد التحقق. |
| `update-status` | للمدير فقط. يتحقق من شروط الحالة، يسجل التاريخ، يرسل الإيميل، ينشئ إشعارًا. |
| `request-lookup` | الكود + الإيميل، أو `access_token`: لصفحات `/answer` و`/review`. |
| `submit-answers`، `submit-request-review`، `submit-service-review` | استقبال الإجابات والتقييمات. |
| `postpone-request` | للزميل، بشروط البند 2. |
| `post-broadcast` | حدود الصديق اليومية. |
| `guest-chat` | محادثة الزائر (الاسم إجباري + Turnstile + حد إرسال). |

الأوقات والتواريخ كلها تُحسب بتوقيت `Asia/Riyadh`. التواريخ تُخزن ميلادية (`date`) وتُعرض هجرية افتراضيًا (`islamic-umalqura` عبر `Intl`).

## ٨. الصفحات

| المسار | المحتوى |
|---|---|
| `/` | الواجهة (الشمعة والعدادات)، ثم الأعمال، ثم الاستمارة، ثم زر "سجل الدخول واحفظ بياناتك". |

| `/privacy` | سياسة الخصوصية. |
| `/admin` | الطلبات، العدادات، الأعمال، المستخدمون والأدوار، التقييمات، المحادثات، الرسائل العامة، الأعياد، أرقام الوالدين. |
